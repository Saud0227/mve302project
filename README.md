Chalmers Tekniska Högskola, Sannolikhet och statistik MVE302

# Installation & användning
För att köra koden, installera dependenserna i `requirements.txt`:
```bash
pip install -r requirements.txt
```
Använd alltid `main.py` för att köra programmet. Ändra innehållet i funktionen `main()` för att testa olika scenarier.
